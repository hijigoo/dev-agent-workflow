Cloud Agent PR

사람이 Copilot 할당 후 수정

CodeQL Autofix와 Cloud Agent는 다릅니다. PR의 지원되는 CodeQL 경고에는 Copilot Autofix가 국소 패치를 자동 제안할 수 있습니다. 여러 파일·호환성·회귀 테스트가 필요한 작업은 Issue를 Copilot에 할당해 Cloud Agent가 별도 PR로 처리합니다.
